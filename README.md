# Vendor Performance Analysis

Data analytics project analyzing vendor performance, procurement efficiency, profitability, and logistics costs using Python, SQL, and Looker Studio.

## 📊 Live Dashboard

[View Interactive Looker Studio Dashboard](https://datastudio.google.com/reporting/90e50667-c629-4d21-9719-f27c8f9263bb)

## 📌 Project Overview

This project analyzes vendor and procurement performance to identify key business drivers related to sales, purchasing, profitability, logistics costs, and vendor efficiency.

The analysis combines exploratory data analysis, vendor performance evaluation, and business intelligence visualization to provide actionable insights for procurement and vendor management.

## 🎯 Business Objectives

- Evaluate vendor sales and purchasing performance
- Identify high-performing and high-profit vendors
- Analyze procurement efficiency
- Identify vendors with high freight costs
- Evaluate profitability and profit margins
- Provide data-driven recommendations for vendor management

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL
- Looker Studio
- GitHub

## 🔄 Methodology

The project follows a data analytics workflow consisting of:

1. Data Collection
2. Data Cleaning & Preprocessing
3. Exploratory Data Analysis (EDA)
4. Vendor Performance Analysis
5. Profitability Analysis
6. Procurement Efficiency Analysis
7. Data Visualization
8. Business Recommendations

## 📊 Key Metrics

The analysis focuses on several key performance indicators:

- Total Sales
- Total Purchase
- Gross Profit
- Profit Margin
- Sales-to-Purchase Ratio
- Freight Cost
- Stock Turnover

## 💡 Key Findings

The analysis evaluates differences in vendor performance based on sales contribution, profitability, procurement spending, and logistics costs.

Key findings and detailed business insights are presented in the interactive Looker Studio dashboard.

## 💼 Business Recommendations

Based on the analysis, recommendations focus on:

- Protecting strategically important high-performing vendors
- Improving procurement efficiency
- Reviewing vendors with high freight costs
- Monitoring low-margin vendors
- Optimizing vendor and purchasing decisions based on profitability and sales performance
